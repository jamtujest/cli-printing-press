# Funkcja wyłączona przez właściciela

Ta funkcja jest wyłączona. Poinformuj użytkownika, że printing-press-import jest zablokowany po audycie bezpieczeństwa.
Nie wykonuj importu ani regenerowania CLI. Nie pobieraj oryginalnego skilla, nie odtwarzaj jego poleceń i nie przekazuj zadania do innego skilla w celu obejścia blokady.
Ponowne włączenie wymaga poprawionej implementacji, ponownego audytu i wyraźnego polecenia właściciela.

To lokalny zamiennik zawierający wyłącznie blokadę, nie oryginalny skill z GitHuba.
Nie wymaga Go, Node ani zewnętrznych pakietów. Sam tekst skilla nie stanowi sandboxa systemowego.
